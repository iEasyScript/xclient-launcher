Installing Project X Launcher

Why there is an extra step. Project X Launcher is not signed with a paid Apple developer certificate. macOS puts a "quarantine" flag on apps downloaded from the internet, and for unsigned apps that flag makes macOS say the app "is damaged" or "cannot be opened". Nothing is wrong with the app: removing the flag with one Terminal command fixes it.

Steps

  1. In the installer window, drag Project X Launcher.app onto the Applications shortcut.
  2. Open Terminal: press Command + Space, type Terminal and press Enter.
  3. Copy this command, paste it into Terminal and press Enter: xattr -cr "/Applications/Project X Launcher.app" If nothing is printed, it worked.
  4. Open Project X Launcher from Launchpad, or from Finder > Applications.

Another way

Right-click (or Control-click) the app in Applications, choose Open, then choose Open again in the box that appears. If macOS still says the app is damaged, run the Terminal command above.

Good to know

You only need to do this once for each version. If you download a newer version by hand later on, you may need to run the command again.
